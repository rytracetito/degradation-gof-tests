# Goodness-of-fit tests for degradation processes

R code from my MSc research internship at the **LMAP** (Laboratory of Mathematics and their Applications of Pau), University of Pau and the Adour Region (UPPA), March to July 2026.

**Topic:** goodness-of-fit tests for homogeneous Gamma and Wiener degradation processes.

## Contents

| Folder | Content |
|---|---|
| `Code T1` | Goodness-of-fit tests for the Gamma and normal distributions (Henze, Villaseñor), Grall-Maës gamma bridge algorithm |
| `Code T2` | Random walk approximation (RWA) of the Gamma process, gamma bridge simulation, level and power studies |
| `Code T3` | Validated goodness-of-fit function for the homogeneous Gamma process |
| `Code T4` | Wiener process: Brownian bridge, Grall-Maës method, new method, power under non-homogeneous alternatives |
| `Code T5` | Sampling plans, level and power of simple tests for the Wiener process |
| `Code T6` | Multiple trajectories: Grall-Maës approach and new approach |
| `Code T7` | Bridge approaches with multiple trajectories, application to real GaAs laser degradation data |
| `Code Source`, `Code G` | Consolidated versions of the main functions |
| `Approche Edith`, `Approche Ghislain` | Alternative approaches studied during the internship |

## Tools

R, R Markdown, parametric bootstrap, Monte Carlo simulation.
